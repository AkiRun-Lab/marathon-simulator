# 🍊 マラソンペース計算ツール (Marathon Pace Calculator / MPC)

**物理モデル（勾配・風・空気抵抗・気温）** に基づき、世界中のマラソンコースを「一定の出力（パワー）」で走り切るための最適なペース配分を計算するWebアプリケーションです。

VDOTや目標タイムを入力するだけで、コースの起伏や当日の風向き・気温を考慮した「攻めのペース戦略」を誰でも簡単に作成できます。

## 🏃 バージョン情報
**Version**: 1.4.1 (2026-04-19)

## ✨ 主な特徴
*   **物理ベースの計算**: ジャック・ダニエルズのVDOT理論とMinettiの勾配コストモデルを融合。
*   **世界中のコース対応**: GPXファイルを読み込むことで、あらゆるマラソンコースに対応（愛媛、東京、ボストン、ベルリンなど）。
*   **環境条件の考慮**: 風速・風向き（16方位）・気温、上り坂での強度設定（Hill Strategy）など、きめ細やかな設定が可能。
*   **気温補正**: Ely et al. (2007)、El Helou et al. (2012) の学術研究に基づき、気温に応じた予想タイムの自動調整を実装。
*   **標高補正**: Péronnet et al. (1991) の理論モデルに基づき、GPXの平均標高（海抜 m）からタイム遅延を推定。500m 以下は影響ゼロ（国内主要大会は対象外）。UI で ON/OFF 切り替え可。
*   **高度なデータ処理**: 5m精度のリサンプリングと動的な標高平滑化により、ノイズを除去しつつコース特性を正確に反映。
*   **コース比較機能**: 現在のコンディションで走った場合のタイム差やコース難易度を他コースと比較可能。
*   **コース難易度**: シミュレーション結果 / 目標タイム で算出（1.000 = 目標通り、1.027 = 約2.7%増）。
*   **スマホ最適化**: レース当日の移動中やスタート前でも操作しやすい、モバイルファーストなUI設計。
*   **ダークモード**: ダークテーマを標準採用。

```bash
python3 -m streamlit run app.py
```

## 📂 ディレクトリ構成
*   `app.py`: アプリケーション本体
*   `data/`: GPXデータおよびVDOTテーブル
*   `lib/`: 計算処理モジュール群
    *   `physics.py`: 物理計算エンジン
    *   `pacing_strategy.py`: 戦略ロジック
    *   `course_data.py`: コースデータモデル
    *   `gpx_handler.py`: GPX解析・平滑化
    *   `vdot_handler.py`: VDOT計算
    *   `temperature_adjustment.py`: 気温補正モジュール
    *   `altitude_adjustment.py`: 標高補正モジュール
*   `tests/`: テストコード
*   `.streamlit/config.toml`: Streamlit設定（ダークモード強制）
